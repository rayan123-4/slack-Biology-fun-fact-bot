# slack-Biology-fun-fact-bot

A biology themed slack bot with many features.

## Commands:

| Command      | Description                                                   |
| ------------ | ------------------------------------------------------------- |
| `/biology_fun_fact_bot-ping`       | Replies with latency and Hello! Pong!   |
| `/biology_fun_fact_bot-help`       | Lists all available commands.           |
| `/biology_fun_fact_bot-animalfact` | Displays a random animal fun fact       |
| `/biology_fun_fact_bot-animalimg`  | Displays a random animal image          |
| `/biology_fun_fact_bot-anatomy`    | Displays a random anatomy fun fact      |

## Api's used:
- https://docs.some-random-api.com/endpoints/Facts
- https://docs.some-random-api.com/endpoints/Image
